# Ideen

Sammelplatz für noch nicht durchdachte Ideen. Konkrete Vorhaben werden über
OpenSpec (`/opsx:explore`, dann `/opsx:propose`) zu einem Change und hier
gestrichen oder verlinkt.

Status: `roh` · `geklärt` · `als Change angelegt` · `verworfen`

## Changelog anlegen

- Status: roh
- Offen: Format (z. B. Keep a Changelog), manuell oder generiert, Bezug zu
  OpenSpec-Changes.

## Release-Workflow definieren

- Status: roh
- Offen: Versionierung, Tagging, Build und Veröffentlichung (PyPI?),
  Zusammenspiel mit Changelog und Lizenz.

## Schönes README.md bauen

- Status: Roh
- Offen: Ein README bauen, was animiert das Tool einzusetzen
- z.B. mit Screenshost
- z.B. mit Badges bzgl. der Codequalität etc.
